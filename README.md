# Python Autoclicker

Python autoclicker with a GUI, configurable click intervals, and hotkey control. Automated the one task too tedious to exist. Never clicking again.

## Features

- GUI with start/stop controls
- Configurable click interval (milliseconds)
- Hotkey toggle (start/stop without touching the window)
- Left, right, and middle click support
- Click counter

## Requirements

```bash
pip install pyautogui pynput
```

## Run

```bash
python autoclicker.py
```

## Usage

1. Set your desired click interval
2. Position your cursor where you want clicks
3. Press the hotkey or hit Start
4. Press the hotkey or hit Stop when done
